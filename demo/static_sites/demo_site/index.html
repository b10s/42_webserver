POST text body

This form sends a regular POST request to /upload/posted.txt. It is useful for checking POST handling from a browser.



Upload file (raw bytes)

This upload uses JavaScript to send the selected file as raw bytes. It does not use multipart/form-data, because this server does not support multipart parsing.
